

# Quản lý Học phí Trung tâm Tiếng Anh (TTA)
## PHẦN 1:
## Giới thiệu dự án
Hệ thống được thiết kế nhằm tự động hóa quản lý học viên, tối ưu tính toán học phí và hỗ trợ kế toán kiểm soát tài chính minh bạch, chính xác.
## Cấu trúc thư mục
Dự án được phân chia thành các thư mục chức năng rõ ràng:

| Thư mục / File | Nội dung chính |
| :--- | :--- |
| `archive/` | Lưu trữ dữ liệu cũ và tài liệu sao lưu định kỳ |
| `data/` | Chứa các file bảng tính Excel (`hoc_phi_thang_10.xlsx`, `hoc_vien_khoa_3.xlsx`) |
| `docs/` | Tài liệu hướng dẫn và báo cáo kỹ thuật |

## Quy trình đăng ký học tại TTA
1. Học viên chọn khóa học phù hợp với nhu cầu và trình độ tiếng Anh.
2. Điền thông tin vào phiếu đăng ký và xác nhận thời gian học (số tháng).
3. Thanh toán học phí và nhận thông tin tài khoản truy cập hệ thống từ kế toán.
